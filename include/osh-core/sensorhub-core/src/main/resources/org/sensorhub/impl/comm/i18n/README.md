# TCP and UDP Communication Providers

These providers connect sensor drivers to remote devices over IP networks.

## Configuration

- Select TCP for a connection-oriented stream or UDP for datagrams.
- Enter the remote host and port. Set the local interface or leave it on automatic selection.
- TCP connections can include a username, password, and TLS protection.
- Configure connection timeouts, reconnection behavior, and reachability checks when the selected provider offers them.
