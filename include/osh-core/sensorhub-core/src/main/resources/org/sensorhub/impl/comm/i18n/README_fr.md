# Fournisseurs de communication TCP et UDP

Ces fournisseurs connectent les pilotes de capteur à des périphériques distants sur des réseaux IP.

## Configuration

- Sélectionnez TCP pour un flux orienté connexion ou UDP pour des datagrammes.
- Saisissez l'hôte et le port distants. Définissez l'interface locale ou conservez la sélection automatique.
- Les connexions TCP peuvent inclure un nom d'utilisateur, un mot de passe et une protection TLS.
- Configurez les délais, la reconnexion et la vérification d'accessibilité lorsque le fournisseur sélectionné les propose.
