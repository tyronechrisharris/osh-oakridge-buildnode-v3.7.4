# Πάροχοι επικοινωνίας TCP και UDP

Αυτοί οι πάροχοι συνδέουν τα προγράμματα οδήγησης αισθητήρων με απομακρυσμένες συσκευές μέσω δικτύων IP.

## Διαμόρφωση

- Επιλέξτε TCP για ροή προσανατολισμένη σε σύνδεση ή UDP για αυτοδύναμα πακέτα.
- Εισαγάγετε τον απομακρυσμένο κεντρικό υπολογιστή και τη θύρα. Ορίστε την τοπική διεπαφή ή αφήστε την στην αυτόματη επιλογή.
- Οι συνδέσεις TCP μπορούν να περιλαμβάνουν όνομα χρήστη, κωδικό πρόσβασης και προστασία TLS.
- Διαμορφώστε τα χρονικά όρια σύνδεσης, τη συμπεριφορά επανασύνδεσης και τους ελέγχους προσβασιμότητας όταν παρέχονται από τον επιλεγμένο πάροχο.
