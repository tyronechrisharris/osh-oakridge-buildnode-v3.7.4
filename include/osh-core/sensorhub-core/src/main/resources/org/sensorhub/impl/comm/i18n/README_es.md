# Proveedores de comunicación TCP y UDP

Estos proveedores conectan los controladores de sensores con dispositivos remotos mediante redes IP.

## Configuración

- Seleccione TCP para un flujo orientado a conexión o UDP para datagramas.
- Introduzca el host y el puerto remotos. Establezca la interfaz local o mantenga la selección automática.
- Las conexiones TCP pueden incluir nombre de usuario, contraseña y protección TLS.
- Configure los tiempos de espera, la reconexión y la comprobación de accesibilidad cuando el proveedor seleccionado los ofrezca.
